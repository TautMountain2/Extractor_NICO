# Interfaz

La aplicación local tiene cuatro vistas principales:

- **Resumen**: estado general de la base y últimas cargas.
- **Actualizar**: ejecución de sincronización manual y carga de inbox.
- **Exportar**: filtros y descarga a CSV, Parquet o DTA.
- **Diagnóstico**: logs y archivos detectados.

## Criterios de diseño

- operación local
- baja fricción
- filtros explícitos
- exportación reproducible
- acceso directo desde escritorio
