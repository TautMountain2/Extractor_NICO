# Operación

## Flujo inicial

1. Instalar dependencias.
2. Inicializar base.
3. Ejecutar carga histórica.
4. Validar cobertura y métricas.
5. Crear acceso directo y tarea programada.

## Operación recurrente

- lanzar sincronización
- revisar logs
- exportar subconjuntos analíticos

## Diagnóstico rápido

- `tradehub status`
- `tradehub ingest-inbox`
- `tradehub sync --mode browser`
